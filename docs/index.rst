Welcome to Activity Logger's documentation!
===========================================

Application Overview
=====================

This application is a comprehensive activity logger designed to help users track their achievements in the gym. It provides a robust platform for logging workouts, tracking progress, and participating in challenges. The primary features of the application include:

User Profiles
-------------

Users can create profiles that include personal information and a profile image. These profiles allow users to log in and access their personalized workout data and challenge progress.

Base Exercises
--------------

The application includes a database of base exercises, each associated with a specific body part and type of equipment. Users can browse and select from these exercises when creating workouts. Each exercise includes details such as name, body part, equipment, and an optional description and image.

Workouts
--------

Users can create and log workouts, which are collections of exercises performed during a single session. Each workout is associated with a user and includes a title and creation date. Users can add exercises to their workouts and track their performance for each exercise.

Exercise Entries
----------------

For each exercise within a workout, users can log detailed statistics, including repetitions, weight lifted, and cardio duration. This allows users to track their progress over time and analyze their performance for each exercise.

Challenges
----------

The application features a challenge system where users can join specific challenges to compete or collaborate with others. Each challenge is associated with an exercise and includes goals such as target repetitions, weight, or cardio duration. Challenges have start and end dates, and users can track their progress throughout the challenge period.

User Challenges
---------------

Users can participate in multiple challenges, and their progress is tracked individually. This allows users to engage with the community, set goals, and achieve new milestones in their fitness journey.

Key Benefits
------------

- **Personalized Tracking:** Users can log detailed statistics for each exercise, helping them monitor their progress and adjust their workouts accordingly.
- **Community Engagement:** By participating in challenges, users can engage with the community, set competitive goals, and stay motivated.

In summary, this application is a powerful tool for gym-goers looking to track their progress, stay motivated through challenges, and achieve their fitness goals. It combines detailed exercise logging, community engagement, and robust data management to provide a comprehensive fitness tracking solution.
